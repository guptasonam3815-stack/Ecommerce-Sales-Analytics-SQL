# E-commerce Sales Analytics (SQL)

## 📌 Project Overview
This repository contains a comprehensive SQL-based data analytics project focused on analyzing e-commerce business performance, customer behavior, and sales trends. As an aspiring Data Analyst with a strong background in Mathematics, I have designed optimized SQL queries to transform raw transaction logs into actionable business insights similar to metrics tracked at top e-commerce platforms like Flipkart.

## 📊 Business Metrics Analyzed
- **Month-on-Month (MoM) Revenue Growth Rate:** Tracks monthly financial progress using SQL window functions (`LAG()`).
- **Customer Segmentation (RFM Analysis):** Categorizes users into high, medium, and low-value segments using percentile ranking (`NTILE()`) based on Recency, Frequency, and Monetary metrics.
- **Product Performance:** Identifies top-selling product categories and inventory turnover insights.

## 🛠️ Tech Stack & SQL Concepts Used
- **Database:** PostgreSQL / MySQL
- **Advanced SQL Techniques:** Window Functions (`LAG`, `LEAD`, `RANK`), Subqueries & CTEs, Advanced Joins, Aggregate Functions, and Data Cleaning.
